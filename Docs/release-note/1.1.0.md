## v1.1.0 — 生态科档案 Ecology Section Archive

首个 ECO 接入版本：开源项目 floral-notepaper 全面重制为《明日方舟》莱茵生命生态科风格的本地便签档案终端，业务能力完整保留。

### 品牌重制 | Rebrand

- 应用更名为「生态科档案 Ecology Section Archive」，窗口标题、任务栏、托盘、关于面板、快捷便签与磁贴窗口等全部品牌文案同步更新
- 全套应用图标重绘为生态科六边形叶片徽标
- 界面重塑为生态科数据终端风格：浅灰绿底色、生态青强调色、切角多边形、菱形网格、扫描线、HUD 角标与呼吸六边形空状态
- 引入 Saira / Michroma / IBM Plex Mono 字体组合

### ECO 接入 | ECO Integration

- 新增 `eco-manifest.json`（spec: eco/1），声明启动与依赖装配清单
- Release 改为仅提供 ECO 友好压缩包 `ecology-section-archive-1.1.0-eco.tar.gz`（完整源码树），不再附带安装器
- 保留 `npm run start` 调试入口与 `start.bat` / `start.ps1` 一键启动脚本

### 说明 | Notes

- 基于 [floral-notepaper](https://github.com/Achilng/floral-notepaper) v1.1.0（MIT），感谢上游作者与贡献者
- 前后端技术栈与后端实现零改动，96 项测试全部通过
- 本应用基于 Tauri，ECO 种植后首次启动需本机具备 Node.js 24+ 与 Rust 工具链
